# 📊 E-Commerce Dashboard

## 📌 Project Overview

This repository contains a Streamlit-based interactive dashboard designed for E-Commerce analytics. The dashboard helps analyze product sales, customer reviews, and payment trends to gain actionable insights.

## ⚡ Features
- 📈 **Data Processing**: Cleans and transforms raw e-commerce data.
- 📊 **Interactive Visualizations**: Uses Matplotlib and Seaborn for data visualization.
- 💳 **Payment Analysis**: Examines different payment methods and trends.
- 🌐 **Streamlit**: Deploy the dashboard.

## 🛠 Setup & Installation

Follow these steps to set up and run the dashboard:

1️⃣ **Create a Virtual Environment**
```
conda create --name main-ds python=3.9
conda activate main-ds
```

2️⃣ **Install Required Packages**

```
pip install numpy pandas scipy matplotlib seaborn jupyter streamlit babel
```

3️⃣ **Navigate to the Project Directory**

```
cd "D:\Proyek akhir"
```

4️⃣ **Run the Streamlit App**

```
streamlit run dashboard-ecommerce.py
```
